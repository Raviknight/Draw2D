# DrawingKit

A FreeCAD 1.1 workbench that makes TechDraw drawings quicker, inspired by how Onshape drawings feel. It sits on top of TechDraw: every page and view it creates is an ordinary TechDraw object, so you can keep editing them with the normal TechDraw tools.

The **DrawingKit** workbench has the DrawingKit buttons plus TechDraw's own view, dimension, centre-line, annotation and export tools, so you can make a whole drawing without switching workbench. The DrawingKit buttons are also added at the end of TechDraw's *TechDraw Pages* toolbar, for when you are in TechDraw. (Double-clicking a page in the tree still switches to TechDraw; that is TechDraw's own preference, *switch workbench on click*.)

Status: early version (0.8), not yet in the Addon Manager.

## Commands

The buttons sit on four toolbars: **DrawingKit views**, **DrawingKit dimensions**, **DrawingKit annotation** and **DrawingKit tables**.

### Views

| Button | What it does |
|---|---|
| **Drawing standard (ISO / ASME)** | One standard for everything DrawingKit draws, so conventions never mix. *Auto* (the default) follows TechDraw's dimension standard preference. It sets section and detail captions (ASME "SECTION A-A", "DETAIL B SCALE 2 : 1"; ISO "A-A", "B (2 : 1)"), the projection of new sheets (ISO first-angle, ASME third-angle) and the style of dimensions DrawingKit makes; the tolerance frame offers only that standard's symbols (ISO 1101: UZ, CZ; ASME Y14.5: Ⓤ, Ⓢ, ▷, dynamic profile, ST, CF, with symmetry and concentricity marked as not in ASME Y14.5-2018); weld symbols get ISO 2553's dashed line or none (AWS A2.4). *Update this sheet* brings an existing sheet's captions, weld lines and dimension style in line. |
| **New drawing sheet** | Pick a paper size (ISO A4–A0, ANSI A–E) and orientation, and get a page with DrawingKit's frame and title block. If a part is selected you can add its standard views in the same step. |
| **Add standard views, fitted** | With a 3D part selected: adds front, top and right views (and an optional isometric) as a projection group. The front view is the part's most descriptive face, turned so its longest side runs across the page (a flat flange shows its round face). The scale is the largest standard scale (1:1, 1:2, 1:5 … 2:1, 5:1 …) that fits beside the title block. The title block is filled in from the part. |
| **Projected view by pointing** | Select a view, then move the mouse: a preview shows the view you'd get to the right, left, above, below or at a corner (isometric-style). Click to place it; click again for more; Esc to stop. From the front view it joins the projection group; from any other view it becomes a separate view that stays lined up with its parent. |
| **Section by cut line** | Select a view and click on it where the cut goes: one point for a straight cut, or several for a stepped (zig-zag) cut through several features. Segments snap to horizontal/vertical. Right-click or Enter, then click where the section view goes; the arrows point that way. Lettered A-A, B-B … automatically (I, O and Q are skipped). A stepped cut must cross the part from one side to the other. |
| **Aligned section** | For features at an angle, like holes on a bolt circle: click out through one feature, the centre, then out through another at any angle; the angled part is swung flat into the section (TechDraw's aligned complex section). |
| **Hatch by part** | Assembly sections, straight, stepped or aligned: each part's cut faces get their own hatch, at 45°, 135°, 30°, 120°… with closer spacing for small pieces; identical parts share a hatch, and the lines run edge to edge. One general-purpose hatch for every material by default, as ASME Y14.2 and ISO 128 do (the material goes in the parts list); switch on *Patterns by material* in the Hatch by part pop-up for steel double lines, brass/bronze/copper solid and dashed, aluminium cross-hatch, plastics and rubber dashed. Shafts, pins, bolts, screws, keys, rivets, nuts, washers and dowels cut lengthwise are drawn whole (uncut, laid over the section), as ASME Y14.3 and ISO 128 have them; cut across, they are hatched like any other part. To choose for a part yourself, add a boolean property `DrawingKitNoSection` to any part to choose for yourself. In an aligned section each swung-flat piece is matched to what TechDraw drew, so the hatch follows its layout; parts cut lengthwise there are drawn whole too, turned like the piece TechDraw swung flat. Done automatically when a section cuts two or more parts (an aligned one as soon as TechDraw has drawn it); press it again after changing the model. |
| **Edit a part's hatch** | Click a part in a section hatched by part: set its angle, spacing (mm on paper) and pattern, switch its hatching off (drawn uncut) or on (e.g. a pin you do want cut), or reset it. Your choice is kept whenever the hatch is redone. |
| **Detail view by clicking** | Click the centre of the area to enlarge, click again to set the circle, then click where the detail goes. It gets the next free letter and a standard scale, e.g. "DETAIL A (5 : 1)". |
| **Auxiliary view** | Select a slanted straight edge (a face seen edge-on), then click on the side where the view goes: it looks square-on at that face, so the face shows true size, and stays lined up with its parent along the face's normal. |
| **Fit to page** | Picks the scale again so the projection group and the other views fit, then re-centres them, keeping views off tables. A section stays in line with the view it was cut from (a section of the Top view stays beside the Top view); if that doesn't fit, a smaller scale is used. Room is kept round the views for their dimensions and callouts, and a table sitting on them moves to a free spot. Datums, frames and dimensions follow (a dimension keeps its distance from the view's edge when the scale changes). |
| **Scale up / Scale down** | One standard scale bigger or smaller (1:2 → 1:1 → 2:1 …), laid out again like Fit to page. Detail views keep their zoom over their view and move to a free spot if they no longer fit. Scale up refuses if the views would not fit the sheet. With a detail view selected, only that detail changes (it stays larger than its view). |
| **Set scale** | Any scale, standard or not: type 1:3, 3:4, 2.5:1, 0.8 or 150 %; the title block shows it as typed, and the sheet keeps it when tables or notes are added later. A scale at which the views fit but their dimensions and callouts wouldn't is refused, with the largest standard scale that does fit. **Fill sheet (NTS)** zooms the views to fill the drawing area at whatever scale that takes (leaving room for detail views), and the title block says NTS. With a detail view selected, sets that detail's scale. |
| **Hidden lines on/off** | Shows hidden edges as dashed lines (a counterbore seen from the side, say) in the selected views, or in every view on the sheet; click again to hide them. |
| **Shaded isometric view** | A shaded picture of the part or assembly from the drawing's isometric direction: each part in its own colour (as in the 3D view), sharp edges drawn in black, captioned "ISOMETRIC VIEW (SHADED) / REFERENCE ONLY - NOT TO SCALE". Select the parts, a view of them, or nothing (the sheet's parts), then click where it goes, or press Enter for a free spot; views keep clear of it. It is painted without OpenGL and stored in the document. After the model changes, select it and press the button again to paint it anew. |
| **Alternate position (phantom lines)** | Shows a part swung or slid to another position in phantom lines (thin long dash, double dot - ISO 128 / ASME Y14.2), like a handle shown open as well as closed. Click the part in a view (it lights up), then the pivot (snaps to hole centres and corners) and swing it with the mouse in 5° steps; or press Enter instead of a pivot to slide it. Click to place. The phantom lines scale and move with the view and are drawn again when the model changes. Select a view that has some and press the button again to remove them. |
| **Fast editing on/off** | On: the page stops updating itself and views switch to Coarse View, so small edits don't freeze FreeCAD. Off: views go back to full quality and the page redraws once. |

### Annotation

| Button | What it does |
|---|---|
| **Dimension** | Works like the Sketcher's dimension tool. Hover lights up a line, circle, point or circle centre; click one or two, move the mouse to choose, click to place. While you move, the dimension is drawn as it will be placed (extension lines, dimension line, arrows or the angle's arc, and its value), so you can see where it goes before you click. A circle gives ⌀, an arc R (placed outside the circle, the value reads horizontally on a leader with a shoulder; inside, it runs across), a line its length; the two outline lines of a cylinder seen from the side give a ⌀ too; two points or two circles give the distance between them (mouse above/below: horizontal, left/right: vertical, diagonal: true distance; two circles measure centre to centre); a point or circle and a line give the perpendicular distance; two parallel lines the distance between them; two other lines the angle. The value shows next to the mouse before you click. Stays on for the next dimension until Esc. |
| **Ordinate / baseline dimensions** | Many features from one zero edge or point, picked like the Dimension tool. **Ordinate**: "0" at the zero and each feature's distance on an extension line ending in one row beside the view, values that would collide spread out with a short jog (drag the row to move it). **Baseline**: stacked TechDraw dimensions from the zero. **Chain**: end-to-end dimensions in one row. Horizontal or vertical; click the zero first, then the features, Enter to finish. |
| **Centerline** | Click two edges (the sides of a hole or shaft seen from the side) or two points: TechDraw's own centerline is drawn midway and follows the view. |
| **Chamfer callout** | Click the slanted chamfer edge, then where the text goes: "1 x 45°" (or "2 x 30°" for other angles) on a leader that stays on the edge. It is a note, so it can be edited and resized. |
| **Centre marks and centre lines** | Centre marks on holes and round features seen end-on, centre lines along their axes seen from the side. Evenly spaced holes round a centre get a bolt circle (dashed pitch circle plus a short radial line through each hole). Run it again to refresh; fillets are left alone. |
| **Hole callouts** | Labels holes as "6X ⌀4.00 THRU" or "⌀5.00 ↧ 10.00": identical holes are counted, through holes say THRU, blind holes get their depth, and counterbored, countersunk and spotfaced holes get the ASME / ISO 129 symbols: "4X ⌀6.60 THRU ⌴ ⌀11.00 ↧ 6.40", "⌀6.60 THRU ⌵ ⌀12.40 X 90°", "⌀6.60 THRU SF ⌀16.00 ↧ 1.00". Tapped holes made with PartDesign's Hole tool get their thread: "2X M6 - 6H THRU", or drill then thread for a blind one: "⌀6.80 ↧ 15.00 M8 - 6H ↧ 12.00" (ISO coarse pitch left out; fine, UNC/UNF and others as FreeCAD names them). Labels keep clear of each other and of other views. The text reads horizontally on a shoulder (TechDraw's *Referencing* style); switch a callout's *Standard And Style* property to *Oriented/Inlined* to have it along the leader instead. They are TechDraw diameter dimensions, so they follow model changes. |
| **Edit dimension** | Select one or more dimensions for an Onshape-style pop-up: text before/after ("3X ", " H7"), decimals, tolerance (none, symmetric ±, deviation +/−, or **limits**: the largest and smallest size stacked, e.g. 0.053 over 0.051, worked out from the measured size and the +/− values and kept up to date when the model changes), **basic** (boxed, theoretically exact) or **reference** (in parentheses), and Ⓔ (envelope requirement) after the size. Basic dimensions carry no tolerance; use them for the dimensions that locate features under a position or profile tolerance. |
| **Datum flag** | Click the datum edge, then where the letter box goes (Enter: straight out). The triangle stays on the edge when the view moves; drag the box anywhere and a leader keeps it connected. For an axis or centre-plane datum (a diameter, a slot's width), select its dimension first: the triangle goes on the dimension line. Lettered A, B, C … automatically. |
| **Datum target** | Datum target point: an X on the part with a leader to the divided circle (e.g. A1, with an optional target-area size). Follows the view. |
| **Geometric tolerance frame** | Pick the characteristic (all 14 ISO 1101 / ASME Y14.5 symbols), tolerance, ⌀ zone, MMC/LMC, and up to three datums each with their own MMC/LMC. Click the toleranced feature, then where the frame goes. Clicking one of several identical holes puts the count (e.g. "6X") above the frame. The leader stays on the feature when the view moves; drag the frame to move it. Tick **Second segment** for a composite frame (one characteristic box over two rows: pattern-locating above, feature-relating below) or a stacked one (each row its own characteristic). **Modifiers…** adds the zone modifiers Ⓤ (unequal profile, with its offset), CZ (common zone), Ⓟ (projected zone, with its height), Ⓕ (free state) and Ⓣ (tangent plane), the **all-around** circle on the leader, and **between** (J ↔ K) under the frame. ASME Y14.5 extras: Ⓢ (RFS) on the tolerance or a datum, ▷ translation on a datum, △ dynamic profile, ⟨ST⟩ statistical tolerance and ⟨CF⟩ continuous feature. Select a size dimension first to put the frame under its value (ISO style for a hole's axis); it moves with the dimension. |
| **Surface texture symbol** | ISO 1302 symbol: any process, material removal required (bar) or not allowed (circle), the Ra/Rz value, lay (=, ⊥, X, M, C, R, P), method above the line and all-around. Click the surface's edge: on a top face it stands on the surface, elsewhere it sits on a leader with an arrow. Follows the view. |
| **Weld symbol** | ISO 2553 symbol: fillet, V-butt, square, bevel, plug, spot or edge weld on the arrow side, other side or both; size (e.g. a5) and length; ISO dashed identification line; all-around circle, field-weld flag and the process number in the tail. Click the joint, then where the reference line goes. |
| **Special characteristic flag** | A hexagon flag with your text (SC by default; CC, KC... - it remembers the last one) to mark a special or critical characteristic. With dimensions selected, each gets one just after its value (past any tolerance or stacked limits; above the value on an upright vertical dimension); otherwise click a dimension's value, or anywhere for a flag on its own (e.g. next to a note that explains it). It follows its dimension; drag it to put it somewhere else. |
| **Note** | Type the note (several lines are fine), pick its text size and font, then click where it goes (a note that would run past the frame or onto the title block is slid back inside). Turn on **Leader** to click the feature first: the arrow stays on it when the view moves. Drag the note to move it; select it and press Note again to change the text, size or font. |
| **Text size and font** | Select dimensions, notes, datums, frames, targets or tables and set the text height (2.5 / 3.5 / 5 / 7 / 10 mm or any value) and font. DrawingKit symbols grow with their text, so a frame drawn at 5 mm keeps ISO proportions. With nothing selected it sets the size and font used for new notes, symbols and DrawingKit dimensions, and the title block font of new sheets. The drawing font is **DejaVu Sans** (the plain print font Onshape uses) until you pick another; FreeCAD carries it in its own files, so nothing needs installing. Pick osifont for the hand-lettered ISO look. |

### Tables and title block

| Button | What it does |
|---|---|
| **Parts list** | Select a view of an assembly (an App::Part or similar group of parts): a parts list goes above the title block, identical parts counted together. Columns: ITEM, PART NO., DESCRIPTION, MATERIAL, QTY (ASME Y14.34 order; ISO puts QTY second). PART NO. comes from a PartNumber (or Part_Number, PartNo) property on the part if it has one, else its name; DESCRIPTION from a Description property or the part's FreeCAD description (Label2). Every cell can be edited on the sheet. Balloons with the item numbers are placed round the view, clear of other views, each with a dot on its part. If the table lands on a view, the sheet is fitted again so the views move off it; balloon leaders never cross. |
| **Balloon** | Click a part, then where the balloon goes: it gets that part's item number from the parts list (or the next free number). TechDraw's own balloon, so it can be dragged and restyled. |
| **Hole table** | Select a view: every hole seen end-on gets a tag (A1, A2 … one letter per size) that follows the view, and a table lists each tag's X / Y from the part's lower-left corner and its size. |
| **Fill title block** | Fills empty title-block fields from the part (name, material, drawing number) and your FreeCAD author name, and numbers the sheets "1 / N". Fields you have typed in are kept. Also done automatically when you add standard views. |
| **Title block…** | Every title-block field in one form (you can also click a field's green square on the sheet, as in TechDraw). Fields that are the same on every drawing (company, approved by, general tolerances, units, X.X / X.XX / X.XXX and angle tolerances, finish) can be saved as your defaults, or to a company file (JSON, e.g. on a shared drive) that everyone points DrawingKit at. New sheets start from DrawingKit's built-in values (ASME: inches, ±.02 / ±.01 / ±.005, ±0.5°), then the company file, then your own defaults. **General tolerances by size** (the usual way on metric drawings, instead of X.X / X.XX / X.XXX): "Tolerances by size…" in the form edits a table of size ranges (over, up to, ±) for lengths and for angles (by the shorter side - or one tolerance for all angles, e.g. ±1°, or none), starting from an ISO 2768-1 class (f, m, c, v) or your own rows (e.g. 0–2 mm ±0.01, 2–6 mm ±0.02). It goes on the sheet above the title block, views keep clear of it, and it is saved with your defaults or the company file so new sheets get it too. One way per sheet: while a sheet has the table, its title block drops the X.X / X.XX / X.XXX values (the ISO row keeps units and finish; the ANSI block says TOLERANCES: SEE TABLE), and gets them back if the table is removed. The tolerance row on top of the title block comes on for ASME or once your defaults use it, and can be switched on or off per sheet in the form. **ANSI layout** (ASME Y14.1 style, sheets at least 210 mm wide inside the frame): an "UNLESS OTHERWISE SPECIFIED" block (units, .X / .XX / .XXX / .XXXX and angle tolerances, interpret per, surface texture and edge notes), projection symbol and sheet size, next to company name and address, two-line title, drawing number, rev, "SHEET 1 OF N", material, finish, drawn / checked / approved, date and scale. New sheets use it for ASME drawings (or always / never: "New sheets" in the form); the form also switches a sheet between ISO, ISO + tolerance row and ANSI as soon as you pick one, keeping what you typed. |
| **Design title block…** | Draw your own title block. Start from a blank block, a copy of DrawingKit's ISO block, a sample with the tolerances by size and a logo, or a wide (280 mm) sample with room for the general notes (inch tolerances, burrs and edges, draft angle, fillet and corner radii, surface finish, specifications, hardness), then click a cell to pick it, drag the lines between cells to move them, and split or merge cells. Each cell holds one thing: a **field** (typed per drawing or filled from your defaults: drawing number, material, drawn by, checked date, or a name of your own; up to 12 lines for notes, each line its own entry in the Title block form, with the design's text as the starting value), a **surface finish symbol** (√ with its value and a note such as MACHINE), **fixed text** (CONFIDENTIAL running upwards, a property notice), a **picture** (your logo: PNG, JPG or SVG, kept inside the design), the **tolerances by size** (filled from your saved tolerance table, angle tolerance on the last row - no separate table on the sheet), or the **projection symbol**. Each has its own caption, text height, bold and alignment. Save it to your own title blocks or to the company's (a TitleBlocks folder next to the company defaults file), and it becomes a layout in the Title block form and for new sheets. A company can keep as many designs as it likes; with any saved, the New sheet pop-up lets you pick the title block for each sheet. Saving a design again updates the sheets that use it in the drawings you have open, keeping what was typed in them. |
| **Add revision** | Adds the next revision (A, B, C …) with its ECO (change order) number, what changed, the date and who approved it to a revision table (REV, ECO, DESCRIPTION, DATE, APPROVED) at the top right of the frame, and puts the letter in the title block. Revision tables made before the ECO column get one when you next add a revision. |
| **Export PDF / DXF** | Saves the current sheet, or all sheets (one file each: "Bracket - Sheet 1.pdf" …), as PDF, DXF or SVG, named after the drawing number and put next to the FreeCAD file. TechDraw draws every letter of a PDF as an outline, so DrawingKit adds an invisible text layer at each text's place (dimension values, hole callouts, notes, title block fields, table cells): the sheet looks the same, but search, copy-paste and print-reading tools get the real words. Beside each PDF it also writes **Bracket.characteristics.json**: every dimension with its nominal, tolerance (its own, or the title block's general one), type and count (4X), each note line, chamfers, geometric tolerances and surface symbols, numbered top-left to bottom-right with their zone (C4…), plus the title block's general tolerances, for an inspection plan or ballooning tool. (Turn the file off with the DrawingKit preference "Characteristics".) |

Settings open in small pop-ups next to the mouse that show only what's needed (Enter = OK, Esc = cancel); extras such as a frame's second segment sit behind a toggle. In the Note pop-up Enter starts a new line; click ✓ to finish.

New frames, datums, targets, surface and weld symbols keep clear of dimension texts, view captions, balloons, tables and each other: left to their default place they also stay off the views; a spot you click is only nudged off text. A frame put under a dimension moves out together with that dimension's text when it would land on a view.

Datums, frames, targets, tags and tables are TechDraw symbols drawn by DrawingKit: drag them like views, and edit their texts (datum letters, tolerance values, table cells) in their *Editable Texts* property.

**Moving views.** Drag a view by any of its lines or faces (TechDraw on its own only lets you grab the small name label). Projected views stay lined up, as in Onshape: side views slide left-right, top/bottom views slide up-down, the isometric moves freely, and dragging the front view moves them all. Views made with *Projected view by pointing* follow their parent the same way. A quick click still selects edges and faces as usual; hold Alt to drag the TechDraw way. To stop the locking on a group, set its **DrawingKitAligned** property to false.

**Frame and title block.** New sheets use DrawingKit's own template: an ISO 5457 frame with zone letters and numbers, and a 180 × 36 mm title block where every field has its own cell (owner, title, material, tolerances, drawing number, date, scale, revision, sheet, created/approved by). The projection symbol matches the page's first- or third-angle setting, and the scale is filled in for you. Every ISO A4–A0 and ANSI A–E size works in both orientations. Templates are written to your FreeCAD user folder under `DrawingKit/Templates`; double-click a field on the page to edit it, as with any TechDraw template.

Which page a command acts on: a selected page (or a view on it), else the page in the active tab, else the only page in the document.

## Install by hand (until it is in the Addon Manager)

1. Download this repository as a ZIP (green **Code** button → **Download ZIP**) and unzip it, or `git clone` it.
2. Open FreeCAD's user Mod folder. On Windows it is `%APPDATA%\FreeCAD\v1-1\Mod`. On any system, type `App.getUserAppDataDir()` in FreeCAD's Python console (**View → Panels → Python console**); the Mod folder goes inside the folder it prints. Create the `Mod` folder if it doesn't exist.
3. Put the unzipped folder there as `Mod\DrawingKit`, so that `Mod\DrawingKit\InitGui.py` exists.
4. Restart FreeCAD and pick **DrawingKit** from the workbench list.

## Limits of this version

- Fitting uses each view's bounding box, so a rotated or round part may get one scale step smaller than it strictly needs.
- With a template from elsewhere that has no ISO frame ids, Fit to page assumes a 180 × 60 mm title block in the bottom-right corner.
- Detail views keep their own scale and position when you use Fit to page (Scale up / down and Set scale do rescale and move them).
- Centre marks are cosmetic lines: after Fit to page changes the scale, run the button again so the overhang matches the new scale.
- Stepped sections use TechDraw's complex section ("Offset" style), so only right-angle steps are supported.
